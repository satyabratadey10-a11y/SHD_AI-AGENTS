## 2025-02-17 - Accessible Overlay Dialogs with Proper Error Handling and Escape Actions
**Learning:** Modern modal dialogs must inform assistive technologies about their overlay state and focus context. Standard HTML input forms should not have unlabeled or nested-only relationships that screen readers fail to parse correctly. Standard overlay interactions like the `Escape` key and disabled button loading states significantly prevent double-form-submission and improve keyboard-only accessibility.
**Action:** Always wrap custom overlay modals in elements with `role="dialog"`, `aria-modal="true"`, and `aria-labelledby`. Ensure inputs use explicit `htmlFor` and `id` properties. Enable keyboard dismiss listeners (`keydown` on Escape) and prevent submission actions during asynchronous network operations.
